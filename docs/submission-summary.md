A README is a list of promises with no test suite. KEPT builds a graph of every promise, cited to the file and line that states it — a citation that does not resolve never enters it — and binds each to a Kane test. Saving code re-verifies the blast radius; saving documentation reconciles what the suite owes. When a promise goes red, Kane's verdict picks one of three repairs: patch the code, evolve the test, or amend the documentation because the claim was never true. Kane reads the test as the specification, so it cannot separate a regression from a lie. KEPT can, because it knows what it has proven: you cannot break what was never proven to work.
